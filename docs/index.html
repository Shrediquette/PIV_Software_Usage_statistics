Methodology ▼

This tool was built by W. Thielicke (PIVlab). The same metric is applied to every software package. The complete source code and the full methodology (including every search query and a reusable recipe) are public.
How every package is counted (same metric for all): Every software package is counted with the same metric:
  • Exact-phrase full-text search via OpenAlex default.search: software names are searched as quoted exact phrases in the full text (title + abstract + body where indexed). Quotes prevent stemming false-positives.
  • "particle image velocimetry" required: this phrase must appear literally in the text. Guarantees PIV context without relying on ML tags. Eliminates false positives from multi-purpose names (e.g. DaVis, TSI, GPIV).
  • Spelling variants: alternate forms are OR-combined (e.g. "OpenPIV" OR "open piv").
  • Commercial software: the company name must also appear in the text (e.g. "Dantec" AND "Dynamic Studio").
Example filter: default.search:"LaVision" AND "DaVis" AND "particle image velocimetry",publication_year:2010-2025
Known limitation: open-source tools (PIVlab, OpenPIV, …) are almost always named explicitly by authors; commercial tools are sometimes described only as "commercial software" without naming them. This means commercial tools may still be undercounted relative to their true usage, even with full-text search.
Note: OpenAlex covers ~96% of the literature. Only fully completed years (2010–2025) are shown.

Publication Venue Impact (JIF proxy) ▼

Shows the paper-weighted mean 2-year journal citedness of the venues in which papers mentioning each software are published — OpenAlex’s open stand-in for the journal impact factor. Read this carefully: it measures the citation reputation of the journals a tool appears in, not the quality of the software or of the individual papers. It is also strongly field-dependent (e.g. biomedical/microfluidics journals carry higher citedness than experimental fluid-mechanics journals for structural reasons), so tools used in different subfields are not directly comparable here. Bars show n, the number of papers each score rests on — a high score based on only a handful of papers is largely chance and should be read with caution. Treat this chart as a rough indicator, not a verdict.
